# Documentação do produto --- SaaS de Planejamento BIM

Esta pasta reúne os documentos de referência para planejar e desenvolver
uma aplicação SaaS de cronograma interativo e planejamento de capacidade
para projetos AEC/BIM.

## Como usar

1.  Leia primeiro `01-visao-do-produto.md` e `02-requisitos.md`.
2.  Revise as decisões em `12-decisoes-pendentes.md` antes de fixar o
    modelo de dados e as regras de capacidade.
3.  Use os requisitos para rastrear o backlog, os critérios de aceite e
    os testes.
4.  Atualize os documentos conforme as decisões do projeto mudarem.

## Status das definições

A arquitetura e os requisitos abaixo são uma base inicial derivada da
proposta do produto. Decisões ainda não confirmadas estão explicitamente
marcadas como **proposta** ou **pendente**. Este conjunto não substitui
validação técnica, segurança, testes ou revisão das necessidades reais
dos usuários.
